# ut-plugin-payment-eposnow

Epos Now payments plugin for Universal Till (type `payment`, WASM, ADR-0002/0009).

**Status: research.** Whether a third-party till can drive Epos Now card terminals or record payments into Epos Now is being established first — see [ut-docs#5027](https://github.com/universaltill/ut-docs/issues/5027) and the migration epic [ut-docs#4426](https://github.com/universaltill/ut-docs/issues/4426). Nothing here connects to a real shop's Epos Now account.
